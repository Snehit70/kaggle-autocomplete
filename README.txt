Kaggle Autocomplete
===================

Shows code suggestions in Kaggle notebooks as you type, like Google Colab.
Kaggle already has suggestions, but only opens them when you press Tab;
this extension opens them for you.

Install (Chrome, Brave, Edge):
1. Unzip this file.
2. Open chrome://extensions (brave://extensions in Brave).
3. Turn on "Developer mode" (top right).
4. Click "Load unpacked" and choose the unzipped "kaggle-autocomplete" folder.
5. Reload your Kaggle notebook.

Use:
- Start the notebook session (green dot at the top). Suggestions come from it.
- Type a name (2+ letters) or a dot, e.g. "np." or "pd.read", and the list appears.
- Click the extension icon to turn it off or change the delay and minimum letters.

Note: if a word has only one possible match, it may be filled in automatically.
Raise "Min. chars" in the popup if that gets in the way.
